# CS529_FinalProject_CAIDF_visualization
Project Name: CAIDF visualization prototpye 

Team Members: Frank Wang, Keira Wang, Dhiraj Shelke

Brief Introduction: 
A transitions-centered visualization workspace that helps clinicians quickly understand patient status across the Home → ER → Inpatient Unit → Discharge-to-Home journey.
It provides fast comprehension and traceable evidence through multiple coordinated views — including timeline, swimlanes, readiness dashboard, functional heat grids, and medication–problem matrix — built with structured metadata only (no NLP).
